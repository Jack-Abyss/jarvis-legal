Privacy policy – JARVIS

Last updated: 2026-11-12

Who uses this app

JARVIS is a private, self-hosted assistant used only by its owner, on the owner's own Google accounts. It is not offered to the public.

Google user data accessed

  • Google Calendar: reading events and free/busy information; creating or changing events only after the owner explicitly approves each action.
  • Gmail (if enabled): read-only access to search and summarise the owner's messages.

How data is used and stored

  • Data is processed on the owner's own computer, only to answer the owner's requests.
  • OAuth tokens are stored locally on that computer and are never shared.
  • Google user data is not sold, not shared with third parties, not used for advertising, and not used to train AI models. Request text may be sent to a language-model API solely to produce the owner's answer.

Limited Use

JARVIS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
